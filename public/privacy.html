SHIS STREAM

Política de Privacidad

Última actualización: 28 de septiembre de 2026

Esta Política de Privacidad explica cómo funciona SHIS Stream y qué información puede procesarse cuando usas la Activity. SHIS Stream está diseñada para permitir que una persona comparta una transmisión de su Nintendo Switch con espectadores dentro de Discord.

1. Datos que SHIS Stream solicita

SHIS Stream no solicita intencionalmente tu contraseña de Discord, mensajes privados, lista de contactos, información de pago ni contenido de tus servidores. La Activity tampoco crea una cuenta propia para el espectador.

Al abrir la Activity, el servicio genera credenciales temporales de conexión para una sala de transmisión. Estas credenciales se usan únicamente para conectar al espectador con el stream correspondiente y expiran automáticamente.

2. Datos técnicos procesados

Para entregar el servicio, la infraestructura puede procesar información técnica necesaria para una conexión por Internet, como dirección IP, fecha y hora de conexión, información básica del navegador o dispositivo, eventos de conexión y registros de errores. SHIS Stream no utiliza estos datos para publicidad ni para crear perfiles de comportamiento.

3. Video y audio de la transmisión

El video y audio se transmiten en tiempo real para que los espectadores autorizados puedan verlos. SHIS Stream no está diseñado para grabar ni almacenar de forma permanente las transmisiones. El contenido puede ser procesado temporalmente por los proveedores de infraestructura necesarios para transportar el stream.

4. Proveedores externos

SHIS Stream utiliza servicios de terceros para funcionar, incluyendo Discord para alojar la Activity, LiveKit para la comunicación de medios en tiempo real y Railway para alojar componentes del servicio. Estos proveedores pueden procesar datos técnicos conforme a sus propias políticas y condiciones.

  • Política de Privacidad de Discord
  • Política de Privacidad de LiveKit
  • Política de Privacidad de Railway

5. Cookies y almacenamiento local

SHIS Stream no utiliza cookies propias con fines publicitarios. Discord, LiveKit u otros componentes técnicos pueden utilizar almacenamiento o mecanismos necesarios para mantener la sesión y la conexión en tiempo real.

6. Conservación

SHIS Stream no mantiene una base de datos de perfiles de espectadores. Los registros técnicos que puedan existir en la infraestructura se conservan únicamente durante los periodos configurados o requeridos por los proveedores correspondientes.

7. Menores de edad

SHIS Stream está sujeto a los requisitos de edad y demás reglas de Discord. No está diseñado para recopilar deliberadamente información personal de menores fuera de lo necesario para el funcionamiento normal de la plataforma.

8. Seguridad

Se utilizan conexiones cifradas y credenciales temporales para reducir el acceso no autorizado. Aun así, ningún servicio conectado a Internet puede garantizar seguridad absoluta.

9. Cambios a esta política

Esta política puede actualizarse cuando cambien las funciones de SHIS Stream o sus proveedores. La fecha de actualización aparecerá al inicio de esta página.

10. Contacto

Para consultas sobre privacidad o solicitudes relacionadas con SHIS Stream, puedes contactar al desarrollador mediante el repositorio del proyecto: GitHub Issues de SHIS Stream.
