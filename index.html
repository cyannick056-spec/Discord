Ratón y atajos
Clic para seleccionar; doble clic para renombrar; clic derecho para acciones. Arrastra para mover, usa las esquinas para cambiar tamaño y el círculo para girar. Rueda sobre una figura: tamaño; Alt + rueda: giro; Ctrl + rueda: zoom. Mano, botón central o Espacio + arrastrar: desplazar la vista.
Flechas: mover; Shift: pasos grandes; Alt: precisión. Ctrl + D: duplicar; Supr: quitar; L: bloquear; H: ocultar; Ctrl + Z / Ctrl + Shift + Z: deshacer/rehacer; Ctrl + S: guardar. Shift afina el arrastre y ajusta el giro a pasos de 15°. En móvil, pellizca para acercar y desplazar.
Los espacios Espectador 1–5 se llenan por orden de llegada. El filtro y las luces cambian el entorno y las figuras; el vídeo conserva sus colores.
